Alzikrayat: Photo Sharing Web Application

Project Name
Alzikrayat (Advanced Web Technologies Course Project 1)

Simple Description
Alzikrayat is a custom-built, MVC-based photo sharing web application designed from scratch. It features user authentication with secure Bcrypt hashing, persistent last-login session cookies, file uploads stored safely on disk, interactive photo gallery grids, real-time comments, and a custom manual Regular Expression router without third-party frameworks.

Technologies
-Backend:PHP (Pure OOP, PDO)
-Database:MySQL
-Frontend:HTML5, CSS3, JavaScript
-Environment:Apache HTTP Server (via XAMPP)

How to Run
1. Ensure XAMPP is installed and start the apache and MySQL modules.
2. Place the `alzikrayat` project folder inside your XAMPP `htdocs` directory (`C:\xampp\htdocs\alzikrayat`).
3. Import the database schema into MySQL using phpMyAdmin (creating database `alzikrayat_db`).
4. Open your web browser and navigate to:  
   http://localhost/alzikrayat/public/
